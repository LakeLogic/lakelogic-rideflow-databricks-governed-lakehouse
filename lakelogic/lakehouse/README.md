# rideflow_trip_revenue_analytics_copy

A governed lakehouse on Databricks where every table is a data contract. The jobs run those
contracts, so bad rows are quarantined with the rule they broke, every run is logged, and
privacy requests have a job of their own. Change the contract, not the notebook.

## What you get

- **10 source systems in 5 domains**, each with its own job.
- **One Unity Catalog catalog** (`rideflow_trip_revenue_analytics_copy_dev`), one schema per domain.
- **Quarantine, not silent loss.** A row that fails a rule goes to `quarantine_<table>` with the reason.
- **A run log for every contract.** Rows read, written and quarantined, in each domain's schema (`lakelogic_run_log`).
- **Operations built in:** `pl_monitor_slo` (service levels), `pl_privacy_retention` (retention), `pl_privacy_erasure` (erasure requests) and `pl_admin_maintenance` (OPTIMIZE and VACUUM).
- **Runs before real data arrives.** A seed job writes demo data from the contract schemas; no production rows are read.

## Run it

You need the Databricks CLI signed in (`databricks auth login`) and permission to create catalogs.

```bash
cd platform/databricks
./deploy.sh dev     # deploy.ps1 on Windows
```

Then run **`pl_data_00_mesh_orchestrator`**. It creates the catalogs and volumes, seeds demo data, and runs bronze, silver and gold for every system in order. Safe to re-run.

No secrets: the project runs on the workspace identity.

## Where things are

| Path | What it holds |
| --- | --- |
| `contracts/<domain>/<system>/contracts/<layer>/` | The data contracts: the tables, their rules and owners |
| `contracts/<domain>/_domain.yaml` | Defaults every contract in the domain inherits |
| `platform/databricks/` | The Asset Bundle, the jobs and the notebooks they run |
